PROJECT INFORMATION

About this analyzer

A web interface for the repository's existing C++ packet analysis engine.

D

Deep Packet Analyzer

Inspect network captures using the project's real packet reader, parser, DPI protocol extractors, and application classifier.

Web browser→FastAPI→C++ adapter→PCAP parser

What it analyzes

  • Classic Ethernet PCAP captures
  • IPv4, TCP, UDP, and basic ICMP identification
  • Packet records and directional flow summaries
  • HTTP Host, DNS query, and visible TLS SNI metadata

Known limitations

  • PCAPNG is not supported
  • IPv6 and VLAN-tagged traffic are not parsed
  • No TCP stream reassembly
  • Application bytes and payload contents are not displayed
  • Analysis results are held in backend memory
